# Надя выходит замуж — Telegram-бот

Интерактивный Telegram-бот в формате переписки по мотивам студенческого фильма **«Надя выходит замуж»**.  
Пользователь становится собеседником Нади, которая рассказывает о своих трёх мужьях и просит совета.

---

## Как это работает

Бот ведёт диалог в зависимости от пола собеседника.

### Сценарий (для девушки)

| Шаг | Сообщение |
|-----|-----------|
| 1 | «Привет. Давай поговорим начистоту?» → кнопка **Начать** |
| 2 | «Кто ты?» → выбор **Девушка / Парень** |
| 3 | Надя представляется и рассказывает о трёх мужьях — Лёше, Жене, Косте — и о том, что не может отпустить Максима |
| 4 | «Вот ты бы что сделала?» → **А) Поступила бы так же** / **Б) Не пудрила мальчикам мозги!** |
| 5 | Ответ по выбору + финал с приглашением в кино и ссылками |

### Сценарий (для парня)

Тот же поток, но с адаптированными формулировками: Надя объясняет ситуацию «с женской точки зрения» и спрашивает мужского совета:  
**А) Стерпится — слюбится** / **Б) Жалко этих парней!**

## Установка

```bash
# 1. Клонируй репозиторий
git clone <url-репозитория>
cd bot_nadya

# 2. Создай виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate

# 3. Установи зависимости
pip install -r requirements.txt
```

---

## Настройка токена

1. Создай бота у [@BotFather](https://t.me/BotFather) → `/newbot`
2. Скопируй `.env.example` в `.env`
3. Вставь полученный токен:

```bash
cp .env.example .env
# Открой .env и замени значение:
# BOT_TOKEN=123456:ABC-ваш-токен
```

---

## Запуск

```bash
python bot.py
```

В Telegram найди своего бота и отправь `/start`.
